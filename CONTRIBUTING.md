## Submitting Pull Requests

1. **Open an Issue First:** For major features or architectural shifts, please open an issue to discuss your proposal before investing substantial implementation time.
2. **Quality & Tests:** Ensure your changes do not break existing test suites (`pytest`, `npm test` or `vitest`) and pass all linter checks.
3. **Keep Commits Clean:** Write concise, descriptive commit messages.
